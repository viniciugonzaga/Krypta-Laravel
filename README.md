## Tecnologias
- Laravel Breeze
- Tailwind CSS
- SQLite

## Como rodar o projeto
1. `composer install`
2. `npm install`
3. Crie o arquivo `.env` e configure o `DB_CONNECTION=sqlite`
4. `touch database/database.sqlite`
5. `php artisan migrate --seed`
6. `npm run dev`
7. `php artisan serve`

## Atribuição da Equipe
- **Aluno 1**: Desenvolveu a Landing Page e o CSS.
- **Aluno 2**: Configurou o Laravel Breeze e o Banco de Dados SQLite.
- **Aluno 3**: Criou o Seeder e o Dashboard do TCC.
